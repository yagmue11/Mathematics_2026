## 1. State the sizes of matrices A and B

The size of a matrix is determined by the number of rows and columns.

**Matrix A:**
- Number of rows = 2
- Number of columns = 3

Therefore, the size of A is:

$$
\boxed{2 \times 3}
$$

**Matrix B:**
- Number of rows = 3
- Number of columns = 2

Therefore, the size of B is:

$$
\boxed{3 \times 2}
$$

## 2. Read off the entries

The notation $a_{ij}$ represents the entry in row $i$ and column $j$ of matrix A.

Similarly, $b_{ij}$ represents the entry in row $i$ and column $j$ of matrix B.

**For matrix A:**

- $a_{12}$ = Row 1, Column 2 = -1
- $a_{23}$ = Row 2, Column 3 = 5

**For matrix B:**

- $b_{21}$ = Row 2, Column 1 = -2
- $b_{32}$ = Row 3, Column 2 = 1

Therefore:

$$
\boxed{
a_{12}=-1,\quad
a_{23}=5,\quad
b_{21}=-2,\quad
b_{32}=1
}
$$

## 3. Write the second row of A and the first column of B as vectors

**Second row of A:**

The second row contains the numbers 0, 4, and 5.

As a row vector:

$$
\boxed{
\begin{pmatrix}
0 & 4 & 5
\end{pmatrix}
}
$$

**First column of B:**

The first column contains the numbers 1, -2, and 4.

As a column vector:

$$
\boxed{
\begin{pmatrix}
1 \\
-2 \\
4
\end{pmatrix}
}
$$

## Final Answers

1. **Matrix sizes:**
   - A = $2 \times 3$
   - B = $3 \times 2$

2. **Matrix entries:**
   - $a_{12} = -1$
   - $a_{23} = 5$
   - $b_{21} = -2$
   - $b_{32} = 1$

3. **Vectors:**
   - Second row of A = $(0, 4, 5)$
   - First column of B = $(1, -2, 4)^T$
